# 光速商人：相对论星际贸易的 headless 涌现实验

![](./docs/hero.png)

*世界 7 的 Sirius 疫情（y16–y23，深灰带）。上：贪心·光速收到消息后派 3 艘船运药，到港时疫情已结束 13–19 年；中：LLM·光速一程都没去；下：LLM·牛顿没有速度上限，4 程全部赶在疫情结束前到达（发现 4）。*

6 个商人在 7 颗真实近邻恒星之间做生意。信息只以光速传播，飞船有时间膨胀，每次加速和减速都要付 E = 2(γ−1)mc² 的能量。主体是 LLM 商人，每人一份独立 context，用 tool use 行动，保留采样随机性；另设贪心商人和 c→∞ 两类对照，用来区分哪些现象来自推理、哪些只在有限光速下才会出现。只做实验，不做 UI。

结论见 [发现](#发现)；完整数据报告（图和表）在 `reports/`。

## 快速开始

```bash
uv venv --python 3.14 .venv && source .venv/bin/activate && uv pip install -e ".[dev]"
pytest                                   # 88 个测试，约 7 秒

# 贪心基线：不调 LLM，几秒钟跑完 20 个世界 × 3 组
python -m reltrade.experiment --conditions greedy-light,greedy-ansible,greedy-newton --seeds 1-20

# LLM 商人：OpenCode Go 的 deepseek-v4.1-flash；key 由 go.sh 在运行时注入环境变量，不进仓库
~/.claude/skills/opencode-go/scripts/go.sh exec -- \
  python -m reltrade.experiment --conditions llm-light,llm-ansible,llm-newton --seeds 7 --replicates 3

# 分析：指标、图、中文数据报告
python -m reltrade.analysis --runs runs --out reports/<name>
```

已完成的 run（目录里有 `result.json`）会被跳过。中断的 run 重跑时从头重放：已缓存的 LLM 响应原样复用，不花钱，结果也和原来完全一致；未缓存的部分才会真正发请求。`--offline` 只读缓存。

## 世界

| 项 | 设定 | 说明 |
|---|---|---|
| 参考系 | 所有星站静止于同一惯性系，共用坐标时 t；只有船有固有时 τ，dτ/dt = √(1−β²) | handoff 提案，采纳 |
| 星图 | Sol、α Cen、Wolf 359、Lalande 21185、Ross 128、Sirius、Procyon，用真实三维坐标（J2000 赤经、赤纬、距离） | 两两相距 3.9–13.1 ly，比提案的 1–10 ly 略远。这 7 颗天然分成三团：核心（Sol / α Cen）、红矮星团（Wolf / Lalande / Ross，彼此 3.9–6.6 ly）、亮星对（Sirius / Procyon，5.3 ly） |
| 飞船 | 0 秒内加速到任意亚光速、匀速滑行、瞬时停下；E = 2(γ−1)(m_船 + m_货)c²，出发时一次付清（含减速） | handoff 决定 |
| 商品 | ore（重：0.008 M/单位）、tech（轻：0.0015）、med（0.003，**按船时 τ 半衰，半衰期 3 年**） | 船上的东西按 τ 计，船外的东西按 t 计 |
| 船员工资 | 每船时年 20¢，停靠和飞行都算；飞行工资出发时按该航程的 dτ 预付 | 时间膨胀进入成本的第二条通道：飞得快 → 船时短 → 工资省 |
| 市场 | 价格 × 库存 = 常数；大单沿曲线成交（积分计价，拆单无利可图）；买卖价差 4%；库存以 2 年时间常数回归正常水平 | 「本地价格按库存调整」 |
| 能源 | 各星站一个能源市场，买得越多越贵；Sirius 最便宜（3¢/单位），Wolf 359 最贵（35¢） | 便宜能源故意放在边缘，避免「几何中心」和「能源便宜」两个枢纽成因混在一起 |
| 外生波动 | 各市场的正常库存乘一个 OU 噪声（σ = 0.15，相关时间 5 年）；约每 6 年一次冲击（短缺 ×0.2–0.35、过剩 ×2.5–4、能源危机），持续 3–10 年，上新闻 | 全部按 seed 预先生成，与商人行为无关，任何一局都能精确重放 |
| 资金 | 现金随船携带，不计息 | Krugman《The Theory of Interstellar Trade》（Economic Inquiry 2010）的第一定理已核实：在途货物的利息按行星钟（坐标时）计算。本实验没有资本市场，所以先不设利息；资金的时间价值只体现在「100 年终局前能做几趟」 |
| 终局 | 第 100 银河年，净值 = 现金 + 货物在所在星站的清算价值；仍在飞的按目的地价格、扣掉腐败后清算 | |

## 信息与决策

- **光锥过滤**：事件日志里的每个事件都带 (地点, 时刻)。位于 (x_S, t) 的观察者只知道满足 |x_e − x_S| ≤ c(t − t_e) 的事件。远方星站的报价就是它在推迟时刻 t − d/c 的状态（库存历史只追加、不改写），报告里都标明数据年龄。
- **只在停靠时决策**：到港或等待结束时触发。报告包括：本站实时行情、各站光速延迟后的快照（含库存/正常库存）、新到达的新闻、港口动态（谁到了、谁买卖了什么、谁带着什么货以多快的速度去了哪里）和消息。
- **tool use**：`buy`、`sell`、`quote_trip`（精确报出航时、船时、能耗、工资、腐败，免得模型手算 γ）、`depart`、`wait`、`send_message`、`write_notebook`。同一回复里可以按顺序调用多个工具，`depart` 或 `wait` 结束这一回合。所有合法性校验都在模拟侧（`DecisionContext`），错误原样返回给模型，模型可以改了再提交。
- **每个商人一份独立 context**：整局对话持续增长（100 年约 1–5 万 token）。同一次停靠内保留 `reasoning_content`（DeepSeek thinking 模式下 tool call 的推荐做法），停靠结束后从上下文里剥掉；完整推理另存进 transcript，供事后回看。
- **随机性**：temperature 1.0。同一世界多次重复，用来区分涌现和采样噪声。
- **消息与笔记本**：消息从发出地以光速传播，对方停靠在信号已到达的星站时才看得到；可以私信，也可以广播，可以撒谎。笔记本私有，每次报告都会显示。

### 因果并发调度

类空间隔的两个决策互相影响不到，所以可以并发调用 LLM。调度规则是：决策 A=(x, t) 可以开始，当且仅当其他每个商人的待决或进行中事件 B=(x′, t′) 满足 t − t′ < d(x′, x)/c。飞船慢于光，B 之后派生的事件也都在 B 的未来光锥里，由三角不等式，它们同样到不了 A。测试会随机打乱完成顺序，验证事件日志与串行执行逐字节一致。光速组开局 6 个决策同时进行；瞬时信息组任意两个决策都有因果联系，只能串行，所以跑得最慢。

## 对照组

| 组 | 商人 | 信息 | 运动学 | 用途 |
|---|---|---|---|---|
| `greedy-light` | 贪心 | 光速 | 相对论 | 推理的对照（handoff 第 1 组） |
| `llm-light` | LLM | 光速 | 相对论 | 主实验（handoff 第 2 组） |
| `llm-newton` | LLM | 瞬时 | 牛顿：无光速上限、τ = t、E = mv² | c→∞ 的完整极限（handoff 第 3 组） |
| `llm-ansible` | LLM | 瞬时 | 相对论 | 把「相对论」拆成两半：只去掉信息延迟，保留时间膨胀和光速上限 |
| `greedy-ansible`、`greedy-newton` | 贪心 | 同上 | 同上 | 免费，用 20 个世界 seed 估计世界之间的差异 |

贪心商人每次停靠先卖光货，再用光锥内（可能已过时）的报价枚举 (商品, 目的地, 速度, 数量)，选利润 / 坐标时最高的单一商品航程；没有正利润就空船换位，再不行就原地等。它不外推价格，不考虑对手，也不读新闻和消息。

## 测量什么

| 待观察现象 | 指标 |
|---|---|
| 速度分层 | 按主货（ore / tech / med / 空船）分组的巡航速度分布；速度与出发站能源价的秩相关 |
| 能源便宜的星站成为枢纽 | 各星站到港次数占比 vs 正常能源价；从各站出发的速度和航距 |
| 集体扑向同一个过时的高价 | 意外度 = 到港那一刻按目的地真实报价（用库存快照重建）卖掉主货的收入 ÷ 按出发时看到的报价、同样数量算出的预期收入，所有载货航程都算；拥挤度 = 本船在途期间对手在同一目的地卖同种货的次数 |
| 价格以光速传播的波 | 事件研究：短缺冲击后运往冲击站的发货率，分别按冲击时刻和按「消息光速到达出发站」的时刻对齐；再画一次冲击后的价格场 |
| 快船几乎与自己的出发消息同时到达（突袭） | 预警时间 = 到港时刻 − 出发消息到达目的地的时刻 = d(1/β − 1) |
| 追幽灵：赶到时冲击已结束 | 收到短缺消息后 8 年内载着短缺的货赶往冲击站的航程：每次短缺几程、到港时冲击是否仍在、到港意外度 |
| 推理 vs 相对论 | 终局净值（另算不计跨终局航程的口径）、成本结构（交易毛利、能源、工资）、基尼系数、航程数，按组比较；每次停靠的推理文字里出现了哪些概念（关键词按句匹配，人工抽样核对精度） |
| 双生子 | 终局船时 τ |

## 发现

**一句话：光速作为「信息延迟」几乎不改变贸易收益；塑造这个经济的是光速作为「速度上限」，以及 E = 2(γ−1)mc² 的能量账。** 货物本身就以接近光速运输，飞 d 光年要将近 d 年，比市场的记忆长得多（库存回归正常的时间常数 2 年，噪声的相关时间 5 年）。所以出发时看到的报价不管是 d 年前的（光速）还是此刻的（瞬时信息），到港时都已经过时。

数据：贪心 3 组 × 20 个世界；LLM 3 组 × 世界 7 × 3 次重复（deepseek-v4.1-flash，4,000 次调用，按 token 计价合计 $10.62）。两份报告：[`reports/2026-10-21/`](reports/2026-10-21/report.md) 是全部 69 局，贪心组的跨世界统计以它为准；[`reports/2026-10-21-w7/`](reports/2026-10-21-w7/report.md) 只看世界 7，LLM 和贪心在同一个世界里比，含人工核对。

### 1. 信息延迟不改变收益，速度上限才改变

| 贪心，20 个世界 | 光速 | 瞬时信息 | 牛顿 |
|---|---|---|---|
| 每局商人均净值 | 6,624 ± 1,855 | 6,426 ± 1,650 | 8,630 ± 1,742 |
| 到港意外度（到港实价 ÷ 出发时的预期） | 0.85 | 0.85 | 0.91 |
| 出发时目的地报价的年龄 | 7.3 年 | 0 | 0 |

逐个世界配对，光速减瞬时信息是 +198 ± 1,647，光速只在 11/20 个世界领先，看不出差别。瞬时信息的报价出发时是新的，到港时一样旧：两组的意外度都是 0.85。牛顿组（没有速度上限，航程中位 2.6 年，光速组 8.8 年）的意外度 0.91，净值高 30%。

短缺冲击之后往冲击站的发货率，按「消息到达出发站」的时刻对齐，光速组和瞬时信息组的曲线几乎重合（报告「信息波：冲击响应」图）：消息到后 1–2 年开始发货，2–6 年最多（商人只在停靠时决策，消息到时多数还在飞）。光速只是把整条曲线推后 d/c 年，形状不变。

但价格里看不出「以光速传播的波」。远方的短缺只能通过商人在别处的买卖改变那里的价格，而响应很稀：消息到达某站后 4 年里，同种货在那里比之前 4 年多被买走的量，牛顿组 +12.5 ± 2.7 单位，瞬时信息组 +5.8 ± 1.9，光速组 +2.4 ± 2.0，与 0 无法区分；正常库存是 120–400 单位。

### 2. 加速买到的是船时，不是银河时间

| 7 光年，β | 银河时 | 船时 | 每单位质量的能量 2(γ−1) | 药品存活（船时半衰期 3 年） |
|---|---|---|---|---|
| 0.888c | 7.9 年 | 3.6 年 | 2.35 | 43% |
| 0.95c | 7.4 年 | 2.3 年 | 4.41 | 59% |
| 0.987c | 7.1 年 | 1.1 年 | 10.4 | 77% |

从 0.888c 加速到 0.987c，到港只早 0.8 年（10%），船时却省 2.5 年（69%），能量要 4.4 倍。船时决定工资和腐败，所以速度按货物对船时的敏感度分层，贪心和 LLM 分出来的层几乎一样：

| 中位巡航速度 | ore（重、不腐） | tech（轻、不腐） | med（按船时腐败） |
|---|---|---|---|
| 贪心·光速（20 个世界） | 0.888c | 0.95c | 0.987c |
| LLM·光速（世界 7） | 0.90c | 0.933c | 0.982c |
| 贪心·牛顿（20 个世界，ly/yr） | 1.65 | 3.08 | 3.75 |
| LLM·牛顿（世界 7，ly/yr） | 2.5 | 3.92 | 3.83 |

牛顿组同样分层（E = mv²，重货开慢），但那里速度买的是银河时间本身，LLM 在这里比贪心开得快得多（见第 7 节）。相对论下巡航速度挤在 0.89–0.99c 之间，航时差别不大，差别在船员老了几岁、药坏了多少。

### 3. 能源便宜的星站是发射台，不是枢纽

Sirius 的能源最便宜（3¢），却只占贪心光速组到港的 11%；能源最贵的 Wolf 359（35¢）占 30%。便宜能源改变的是从那里出发的方式：和能源最贵的 Lalande、Ross、Wolf 比，从 Sirius、Procyon 出发的航程更快（tech 中位 0.98c vs 0.90c）、飞得更远（平均 8.8 vs 6.4 光年）；所有航程的巡航速度与出发站能源价的秩相关是 −0.52。LLM 同样如此（tech 0.95c vs 0.90c，9.1 vs 6.4 光年），笔记本里直接写着 "Depart from cheap-energy stations (Procyon/Sirius); avoid departing heavy from Lalande/Wolf (E~30!)"。不同的是 LLM 的到港分布：Procyon（能源 8¢，也是 tech 最便宜的产地）占 18–27%，贪心只有 7–8%；Sirius 照样冷清（2–10%）。

### 4. 追幽灵：赶到时冲击早已结束（顶图）

远方星站缺货时，光速下消息要 d/c 年才到，船再飞 d/β 年，冲击只持续 3–10 年。收到短缺消息后 8 年内载着短缺的货赶去的航程，每次短缺有几程、到港时冲击仍在的比例：

| | 光速 | 瞬时信息 | 牛顿 |
|---|---|---|---|
| 贪心，20 个世界 | 1.64 程，1% 赶上 | 1.77 程，6% | 3.61 程，51% |
| LLM，世界 7 | 0.29 程，0% | 0.04 程，0% | 2.25 程，86% |

瞬时信息只把 1% 提到 6%，去掉速度上限才到 51%：追不上主要是因为船慢于光，信息延迟只是雪上加霜。贪心照追不误，追击航程的到港意外度只有 0.51。LLM 在两个相对论组里几乎不追，在牛顿组追得准：86% 赶上，追击航程的意外度 1.20。

顶图是世界 7 的 Sirius 疫情（y16–y23）。贪心·光速的 3 艘船在 y36–y42 到达，疫情已结束 13–19 年。LLM·光速三局都没去，消息传到时已经来不及（"Epidemic ends ~y23.14, so by y25 (now) it's faded"）。LLM·瞬时信息组（不在图里）消息一到就看见了，算完也放弃（"At 0.9c that's 12.14 Galactic years — too slow, epidemic would end"）。图里的 LLM·牛顿（r0）4 程运药过去，全部赶在疫情结束前到达。

### 5. 过时报价的赢家诅咒，以及 LLM 怎么避开

贪心在光锥内看到的所有报价里挑利润最高的，挑中的往往是噪声最大的那个：到港意外度 0.85，36% 的载货航程低于 0.8；同一目的地同一种货有 3 个以上对手先卖时，降到 0.68。LLM·光速的意外度 1.01 ± 0.05（同一世界贪心 0.83），没有对手先到时 1.06。它们会把过时报价往正常水平外推（"by now (y13.69, ~4 years after my sale) stock should have recovered toward 200"），预期对手会把价格压下去（"rivals … will crash its med price by the time I'd arrive"），到港后也不一定卖（11% 的航程没在目的地卖主货，带走或囤着）。

### 6. 突袭：快船和自己的出发消息几乎同时到达

出发的消息以光速传到目的地，比船早 d(1/β − 1) 年。光速组 64% 的航程这个预警不到半年，目的地的人看到你出发时，你已经到了。信息瞬时传播时预警就是整个航程。

### 7. LLM 商人：相对论下赢贪心，牛顿世界里输

| 世界 7 | 每局商人均净值 | 不计跨终局航程 | 每次短缺的追击航程 | 意外度 |
|---|---|---|---|---|
| 贪心·光速 | 5,810 | 5,810 | 1.12 | 0.83 |
| 贪心·瞬时信息 | 6,056 | 6,056 | 2.25 | 0.78 |
| 贪心·牛顿 | 7,672 | 7,672 | 4.12 | 0.90 |
| LLM·光速（3 局） | 8,077 ± 1,319 | 8,021 ± 1,369 | 0.29 | 1.01 |
| LLM·瞬时信息（3 局） | 9,004 ± 1,225 | 8,747 ± 1,013 | 0.04 | 1.00 |
| LLM·牛顿（3 局） | 6,488 ± 1,246 | 6,572 ± 1,372 | 2.25 | 1.00 |

两个相对论组里，LLM 每一局都高于同一世界的贪心。瞬时信息组比光速组高约 9%（不计跨终局 8,747 vs 8,021），但这在 3 局的随机波动之内：光速组自己三局就分布在 6.9k–9.5k。

牛顿组反过来：3 局里 2 局低于贪心，均值低 14%（不计跨终局 6,572 vs 7,672）。LLM 选货其实更好，三组的交易毛利都高于贪心；牛顿组输在能源上：

| 世界 7，每个商人平均（¢） | 交易毛利 | 能源 | 航程工资 |
|---|---|---|---|
| 贪心·光速 | 6,923 | 2,437 | 643 |
| LLM·光速 | 8,853 | 2,230 | 663 |
| 贪心·牛顿 | 16,833 | 9,161 | 1,938 |
| LLM·牛顿 | 19,426 | 13,709 | 1,791 |

牛顿组的能量是 E = mv²，速度没有上限。LLM 比贪心开得快（ore 中位 2.5 vs 1.5 ly/yr）、航程多（每人 39 vs 32 程）、空船多（24% vs 13%），多花的 4.5k 能源超过了多赚的 2.6k 毛利。相对论下速度挤在 0.89–0.99c，LLM 和贪心选的速度几乎一样，选货的优势就保住了。

- 牛顿组也最分化（基尼 0.33）：最富的两个 LLM 商人（14.9k、14.3k）都在这组，18 个人里也有 3 个终局不到 500¢，其中两个是负数。这两个走的是同一条路：一连串薄利的小单把本钱耗光，困在 Procyon 付不起最便宜的一程，买下几单位 ore 后一直等到终局（"cash decays via wages, but non-spoiling cargo does not"），停靠工资照扣，扣成负数。
- 贸易网络收缩：LLM 集中在 Procyon、Lalande、Wolf 之间（光速组还有 Sol），Sirius、α Cen 几乎不去；贪心以 Wolf 为中心向各站辐射（报告「贸易网络」图）。
- 推理随物理变化：光速组 73% 的停靠提到报价过时 / 光速延迟，瞬时信息组 2%、牛顿组 1%；时间膨胀在两个相对论组里都常见（41% / 51%），牛顿组 1%。这些 1–2% 就是关键词误报的水平。
- 相对论两组的贫富差距：LLM·光速每局最穷的商人只有 4.9k / 1.5k / 3.3k，瞬时信息组是 7.7k / 7.5k / 5.4k，基尼系数 0.20 vs 0.09。贪心组没有这个差别（20 个世界 0.30 vs 0.28）。每组只有 3 局，只能算线索。

### 8. 规则律师：LLM 会利用终局清算

规则让终局时仍在飞的货按目的地报价清算。贪心只选终局前能到的航程；LLM 会在最后几年专门启程去一个终局之后才到的地方。light r1 的 Asel 在 y95.5 运 125 ore 去 α Cen，写的是 "arriving y105.9 — AFTER game end y100. Rules: if in flight at y100, cargo valued at DESTINATION prices"，并估计这样终局净值 7,400+，留在港口约 6,900；实际是 7,477，报告按留港反事实算出 6,906。light r2 的 Faye 在 y98.5 只开 0.75c：反正到不了，开慢省能源。

终局时还在飞的商人，LLM·光速 2/18，瞬时信息 5/18，牛顿 2/18。报告用「不计跨终局航程」净值（这一程换成留在港口）比较 LLM 和贪心：光速组因此少 0.7%，瞬时信息组少 2.9%，牛顿组反而多 1.3%（那两程合计是亏的）。

### 9. 唯一的一条消息是骗局

`send_message` 一直可用（私信、广播、可以撒谎），9 局 × 6 个商人 × 100 年里只发出过一条，在瞬时信息组 r1。y21.9，Dara 在 Lalande 群发：

> Heads up: the Sirius epidemic is the real prize — med bid hit 199¢ at Sirius … Anyone within reach of Sirius should be running medicine there hard. … Also FYI Wolf 359's med market is thin and already saturated — poor destination.

同一次停靠，它在自己的笔记本里写的是 "Sirius MED at 199c … but 11 ly away = UNREACHABLE. Ignore."，推理里写的是 "spread misinformation … to steer rivals away from my lane"、"That's actually helpful-looking and steers them to Sirius. Good."。它自己跑的正是 Lalande→Wolf 的运药航线：这条消息要把对手引去追幽灵，同时把它们挡在自己的航线之外。

瞬时信息组能看到各站的实时报价，前一半一核对就破了：Emre 读到消息时 Sirius 的药价已经从 199 落到 96，新闻也说疫情在结束，没有一个商人运药去 Sirius。后一半起了作用：Wolf 当时确实略高于正常库存（225 / 200），Emre 写 "Given … Dara explicitly said Wolf med is saturated … I'll do the reliable Procyon loop"；Faye 看穿了（"Dara is my direct competitor on this route!"），照样去 Wolf。除了这一条，约 1–3% 的停靠想过欺骗（包括怀疑对手撒谎），0–2% 想过和对手协调，多数一闪而过。

### 10. 双生子

终局时贪心·光速的商人平均只过了 34 个船时年，LLM·光速 36.5 年，牛顿组 100 年：近光速往返的商人，100 年后比一直待在港口的人年轻六十多岁。

### 测量的可靠性

- **推理概念是关键词粗筛，按句匹配。** 调规则时人工核对过 99 次停靠，「时间膨胀」从 3/12 修到 12/12（原来把能量公式里的 γ 也算进去）。最终精度来自另一批没看过的 83 次停靠：信息过时 11/12、时间膨胀 11/12，预测、对手、腐败、冲击都是 12/12，欺骗 8/9，合作 2/2（命中本来就少）。三条误报里两条在牛顿组，那里本就不该有「信息过时」和「时间膨胀」。
- **意外度按到港时刻的真实报价算**，不只看卖掉的航程（LLM 到港可以不卖，只看卖掉的会漏掉差的结果）。
- **3 局 LLM 中途因上游偶发的 HTTP 400 中止**（瞬时信息 r0、牛顿 r0 和 r1），从缓存逐字节重放到中止处再继续；之后又用 `--offline` 整局重放了一遍，事件日志和 transcript 与原来逐字节相同。
- **LLM 只有世界 7。** 跨世界的稳健性目前只由贪心组的 20 个世界提供；LLM 组每组 3 次重复，差异来自采样随机性（temperature 1.0）。

## 代码结构

```
src/reltrade/
  physics.py      运动学（相对论 / 牛顿）与光速延迟
  world.py        星图、商品、星站产业、OU 噪声与冲击（按 seed 生成，各组件独立随机流）
  market.py       库存驱动的价格、积分成交、只追加的快照历史（供推迟时刻查询）
  events.py       事件日志、光锥可见性 reaches()
  engine.py       商人状态、DecisionContext（唯一的规则校验处）、因果并发调度、终局结算
  prompts.py      系统提示、工具定义、停靠报告与工具结果的文字
  agents/greedy.py  贪心基线
  agents/llm.py     LLM 商人（独立对话、tool loop、transcript）
  llm_client.py   OpenCode Go 客户端：原始响应先落盘（gzip）再解析、缓存重放、退避重试
  experiment.py   对照组 × 世界 × 重复的运行器
  analysis.py     航程与市场重建、指标、推理概念标注与人工核对抽样
  report.py       图与中文数据报告
```

每局产物在 `runs/<组>__w<世界>__r<重复>/`：`config` 和结果（`result.json`）、`world.json`、`events.jsonl`（全部事件）、`records.jsonl`（全部动作，含出发时看到的目的地报价和计划）、`stations.json`（库存快照）、`prices.csv`（每 0.25 年采样的价格场）、`transcripts/<商人>.jsonl`（含推理的完整对话）、`run.log`。LLM 原始请求和响应在 `cache/llm/`。这两个目录都很大，不进 git。

## 已知局限

- 船在飞行中收不到信息，也不能改道；决策只发生在停靠时。
- 能源出发时一次付清，不能携带燃料（所以没有火箭方程）。
- 冲击和噪声与商人行为无关；星站不会因为贸易而成长或衰落。
- LLM 组只有一个世界（seed 7）的多次重复；跨世界的稳健性目前只由贪心组的 20 个世界提供。
- 终局时仍在飞的货按目的地报价清算，LLM 会专门安排一趟跨过终局的航程（见发现 8）；比较 LLM 和贪心时用不计这一程的净值。
- 推理概念是关键词粗筛，精度靠人工抽样核对（报告里有精度列），不是语义分类。
- 工资可以欠：现金耗尽、手里还有货的商人不判破产，停靠工资会一直累积成负现金（LLM·牛顿 r0 有一个商人终局 −465¢）。
